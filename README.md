# 台風ぶっ飛ばしゲーム

React と Vite で作られた、台風と戦いながら拠点や農地を守るブラウザーゲームです。ゲーム本編と管理画面を同じ開発サーバーから起動できます。

## 動作環境

- Node.js 22.12 以上（または 24 以上）
- npm
- 対応ブラウザー。気象データ取得にはインターネット接続が必要です。

## セットアップと起動

```sh
npm ci
npm run dev
```

Vite が表示するローカル URL を開きます。ルート `/` からアクセスした場合は `/game` に移動します。

- ゲーム: `http://localhost:5173/game`
- 天候管理: `http://localhost:5173/admin`

管理画面で天候を選ぶと、同じブラウザー内のゲーム画面に反映されます。ゲームと管理画面は別タブで開いてください。管理画面の「強制解除」で気象データに基づく天候へ戻せます。

## 遊び方

- タイトル画面から New Game、Load Game、または Continue を選びます。
- ゲーム本編では `A` / `D` で左右に移動し、`Shift` を押しながら移動すると速く進みます。
- `Esc` でメニューを開きます。
- 台風との戦闘では画面のコマンドをクリックするか、`Z`（たたかう）、`X`（まもる）、`A`（回復）、`S`（必殺技）を使います。
- セーブデータは最大10スロットです。ブラウザーのローカルストレージに保存されます。

## 主な機能

- 性別、名前、出身都道府県を設定してゲームを開始
- マップ移動、キャラクター移動、台風との戦闘
- 気象庁の台風・天気データの取得
- `/admin` からの天候強制設定と解除
- 戦闘、農地、防衛、ショップ、台風図鑑、セーブスロット
- BGM・SE・Voice・環境音・Master Volume の設定

## 開発コマンド

```sh
npm run dev       # 開発サーバー
npm run build     # 本番ビルド
npm run preview   # 本番ビルドをローカルで確認
npm run lint      # ESLint
npm test          # Vitest を一度実行
npm run test:watch # テストを監視しながら実行
```

現在のテストは `DamageCalculator` のダメージ計算と防衛行動を対象にしています。Lint は既存の React Hook 依存配列に関する警告を表示する場合があります。

## ディレクトリ構成

```text
public/                 画像、音声などの静的ファイル
src/components/         ゲーム画面で使う共通 UI
src/views/              タイトル、ゲーム、管理などの画面
src/game/context/        ゲーム状態とセーブデータ
src/game/services/       気象、台風生成、ダメージ計算など
src/game/constants/      台風、作物、装備などの定義
src/styles/              画面ごとのスタイル
```
